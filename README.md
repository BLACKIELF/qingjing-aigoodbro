# 清静 · AiGoodBro

帮助关闭安卓手机里有开关的系统广告、推荐内容、营销通知，以及支持的快应用跳转和广告组件。打开即是「一键清静」，自动处理已适配的项目，确认后执行；其他功能收进「更多」。成功清理后会用默认浏览器打开 https://aigoodbro.com，每轮一次。

**1.0.5 · 1112v1** 提供 Mac Apple 芯片与 Intel 版、Windows 安装版与便携版、Android arm64 签名版。下载只认本仓库 [Releases](https://github.com/BLACKIELF/qingjing-aigoodbro/releases)。

「一键清静」沿用超级清静模式，自动处理已适配的广告项，无需逐项选择。开始前备份，跳过未适配的机型脚本，保留服务通知和受保护组件。启动后在后台检查一次更新；需要时可在「更多 → 检查更新」手动检查。发现新版后由你决定是否下载和安装，不在后台自动下载。Windows 与安卓安装前核验文件摘要及应用身份；当前 Mac 包没有 Developer ID 签名，提供 DMG 手动安装入口。

## Mac

- Apple 芯片（M1 及以后），最低系统版本以包内检查结果为准；本版未公证。
- 打开开发者选项与 USB 调试，用能传数据的数据线连接手机，在手机上完成调试授权。
- 首页点「一键清静」，检测设备并确认后执行；连接多台手机时先选目标手机。不要操作手机干扰脚本。
- 系统应用只采用允许的挂起方式；不 root、不解锁、不刷机、不修改系统分区。
- 营销通知、快应用、广告组件有还原入口；App 内的开关按清单手动打开。

## Android

- Android 11 及以上可用内置无线调试配对；Android 8–10 需自行准备已授权的 Shizuku。
- 首次连 Wi-Fi，跟随引导打开开发者选项和无线调试并完成配对。
- 有后台屏支持时可以继续用手机；提示不要碰手机时请等待。
- APK 使用本项目独立签名和应用 ID，可与原版并存。卸载会删除本 App 的备份与授权，不会自动撤销系统改动。

## 范围

- 系统广告、广告跟踪、热榜、负一屏资讯、部分浏览器和商店推广。
- 按通知渠道处理营销信息，保护订单、物流、聊天等服务通知。
- 具体项目依赖机型、系统及机型脚本。第三方 App 自带的开屏广告不在范围内；无关闭开关的内容无法保证消失。
- Mac / Windows 新增原生鸿蒙 HDC 通道，仅接受 API 20 及以上已授权 USB 设备；规则来自 Pura X Max（HOP-AL10）HarmonyOS 7.0.0.111 的上游记录，本项目未做鸿蒙真机复测。安卓 APK 仅用于安卓设备。
- 没有实际手机结果时，不宣称整机去广告验证通过。

本项目为 MIT 开源软件的衍生版本。原始项目、作者说明和完整许可可在软件的“关于清静”中查看；源码保留原始 [MIT LICENSE](LICENSE)。
